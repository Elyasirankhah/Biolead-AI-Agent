# BioLead Slide Outline (8–10 slides)

Use this as the talk track / deck skeleton for a BioLead walkthrough.

1. **Title** — BioLead Evidence Workbench · Research use only
2. **Problem** — Passenger genes look disease-relevant in inflammation but are symptoms, not causes
3. **Product thesis** — Decision workbench: Driver / Passenger / Insufficient, with citations and counter-evidence
4. **Decision framework** — Evidence hierarchy + separate causality / actionability / quality scores
5. **Live workflow** — Disease + candidates → collect → score → falsify → decision brief
6. **Evidence audit** — Source-linked objects, contradiction penalties, abstention when pillars are missing
7. **Demo comparison** — IL4R (Driver) vs S100A8 (Passenger) vs FLG (Insufficient)
8. **Architecture** — Next.js workbench · FastAPI on AWS · deterministic scorer, LLM only for grounded narrative votes
9. **Scale-out** — ALB/ECS, Step Functions, Aurora, S3 provenance, Bedrock, ElastiCache
10. **Roadmap** — Deeper tissue coverage, L2G resolution, and clinician-facing workflows
